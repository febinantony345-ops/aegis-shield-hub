# About this Hub

!!! warning "Fictional training data"
    Aura Workforce is a **fictional company** created for a security training programme.
    All people, accounts, salaries, bank numbers and incidents on this site are invented.
    Nothing here describes a real organisation or a real person.

## What this Hub shows

This Hub lets a reader review the security work for Aura Workforce: findings, a risk register, policies and detection rules. It is built so that a client or auditor can check the evidence without touching anything dangerous.

## What is not published

- The vulnerable practice lab. It runs only on a private machine and is never hosted online.
- Passwords, keys, tokens or any `.env` content.
- Step-by-step exploit instructions that would work against real systems.
- Real names, real email addresses or real personal data.

## Review of the content

Pages are checked with a link checker and a spell check before each release.
