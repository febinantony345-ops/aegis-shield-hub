# Aegis Shield Security Hub

A static security evidence site for a **fictional** company, Aura Workforce, built with MkDocs. All data is invented for a training project.

Pages: executive summary, findings, risk register, policies, detections, hosting options.

The vulnerable practice lab is not part of this repository and is never published.

Build locally:

```
pip install -r requirements.txt
mkdocs build --strict
```
